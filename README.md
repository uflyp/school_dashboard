# School Dashboard

Web Dashboard Manajemen Sekolah menggunakan *PHP Native* dan *Tailwind CSS*.

## Fitur Utama
* Dashboard Aplikasi
* Manajemen Data Sekolah

## Cara Menjalankan
1. Clone repositori ini
2. Pindahkan folder ke xampp/htdocs/
3. Jalankan Apache & MySQL di XAMPP
4. Buka localhost/school_dashboard di browser
